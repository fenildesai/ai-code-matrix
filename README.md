# The AI Code Matrix 🌌

> **The vocabulary, mechanics, and mental models of agentic AI coding in plain English.**  
> Featuring an interactive 3D Knowledge Universe, full Encyclopedia with ELI5 metaphors, and "Context Quest" (a gamified context window & token simulator).

🌐 **Live Web App:** [https://fenildesai.github.io/ai-code-matrix/](https://fenildesai.github.io/ai-code-matrix/)

---

## ✨ Features

- **🪐 3D Knowledge Universe:** Real-time force-directed 3D constellation graph rendering nodes, semantic relationships, and cross-domain connections.
- **📚 Comprehensive Lexicon & Encyclopedia:**
  - **100+ Deeply Curated Concepts** across 8 foundational domains.
  - **20 Ideas That Explain AI (No PhD Required):** Neural Networks, Tokenization, Embeddings, Attention, Transformers, LLMs, Context Windows, Temperature, Hallucinations, Prompt Engineering, Transfer Learning, Fine-Tuning, RLHF, LoRA, Quantization, Vector Databases, AI Agents, Chain-of-Thought, and Diffusion Models.
  - **Full Suite of RAG Architectures:** Naive RAG, Agentic RAG, Graph RAG, Modular RAG, HyDE (Hypothetical Document Embeddings), Self-RAG, and Corrective RAG (CRAG).
  - **Explain Like I'm 5 (ELI5):** Relatable, child-friendly real-world analogies for every single term.
  - **Practical Real-World Examples:** Concrete production code examples and traps to avoid.
- **🎮 Context Quest (Gamified Token Simulator):**
  - Interactive missions simulating production outages and feature builds.
  - Live HUD tracking tokens consumed, dollar cost, and Attention HP.
  - Free-play interactive sandbox demonstrating attention zones, context degradation, and KV cache hits.
- **🌗 Theme Toggle:** Light Mode (default) & Dark Mode with seamless instant switching and persistent local storage.
- **🎵 Web Audio Synthesizer:** Elegant micro-interaction soundscapes synthesized entirely via Web Audio API (with instant mute control).

## 🛠️ Tech Stack

- **Framework:** React 19 + TypeScript + Vite 8
- **Styling:** Tailwind CSS 4
- **Icons:** Lucide React
- **Graphics:** HTML5 Canvas (Custom 3D Projection & Force Simulation Engine)
- **Audio:** Web Audio API Native Synthesizer
- **Deployment:** GitHub Pages via GitHub Actions

## 🚀 Local Development

1. Clone the repository:
   ```bash
   git clone https://github.com/fenildesai/ai-code-matrix.git
   cd ai-code-matrix
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start development server:
   ```bash
   npm run dev
   ```
   Open `http://127.0.0.1:5173/` in your browser.

4. Build for production:
   ```bash
   npm run build
   ```
